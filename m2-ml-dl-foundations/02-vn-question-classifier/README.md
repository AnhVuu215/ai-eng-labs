# 02-vn-question-classifier

> M2 · Nền ML/DL đủ dùng — Khối 2 · Tuần 8–9 · ML cổ điển và thống kê cho eval

**Trạng thái:** ⬜ Chưa bắt đầu

## Mục tiêu

- Thu 300–500 câu hỏi về học vụ (tự viết, nhờ bạn bè viết), gán nhãn 5–8 nhóm (học phí, điểm, tốt nghiệp…)
- Baseline TF-IDF + Logistic Regression; xem ma trận nhầm lẫn
- Bootstrap 1.000 lần để có khoảng tin cậy 95% cho F1
- Phân tích lỗi: đọc 30 câu sai, gom nhóm nguyên nhân

## Tiêu chí đạt

- [ ] có báo cáo F1 kèm khoảng tin cậy; liệt kê được 3 nhóm lỗi chính. Bộ dữ liệu này dùng lại ở M5 (định tuyến) và M7 (fine-tune).

## Lý thuyết cần đọc

- [ ] Train/val/test, cross-validation, overfitting, data leakage
- [ ] Precision, recall, F1, ma trận nhầm lẫn; chọn metric theo chi phí sai
- [ ] Bootstrap để tính khoảng tin cậy; kiểm định so sánh hai mô hình trên cùng tập test
- [ ] Kích thước mẫu: vì sao 30 câu eval không đủ để kết luận
