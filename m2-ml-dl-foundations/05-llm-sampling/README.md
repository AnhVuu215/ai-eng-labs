# 05-llm-sampling

> M2 · Nền ML/DL đủ dùng — Khối 5 · Tuần 15–16 · LLM trong thực tế

**Trạng thái:** ⬜ Chưa bắt đầu

## Mục tiêu

- Gọi một LLM 20 lần cùng prompt ở 3 mức temperature; đo độ khác nhau giữa các câu trả lời
- Tìm kiếm ngữ nghĩa trên các điều khoản quy chế bằng một embedding model đa ngôn ngữ; so với full-text search của M1 trên 20 câu hỏi

## Tiêu chí đạt

- [ ] chỉ ra được loại câu hỏi mà semantic search thắng và loại mà full-text thắng. Đây là lý do cho hybrid search ở M3.

## Lý thuyết cần đọc

- [ ] Pretraining, instruction tuning, RLHF/DPO ở mức khái niệm
- [ ] Sampling: temperature, top-p; vì sao cùng prompt cho ra kết quả khác nhau
- [ ] Embedding model khác LLM sinh text thế nào; model đa ngôn ngữ
- [ ] Hallucination: vì sao xảy ra, vì sao RAG giảm được mà không xóa hết
