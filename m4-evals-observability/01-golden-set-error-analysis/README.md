# 01-golden-set-error-analysis

> M4 · Evals và observability — Khối 1 · Tuần 24–25 · Golden set và phân tích lỗi

**Trạng thái:** ⬜ Chưa bắt đầu

## Mục tiêu

- Mở rộng 50 câu từ M3 lên ≥ 150 câu, ưu tiên câu lấy từ log thật
- Viết hướng dẫn gán nhãn 1 trang; nhờ một bạn gán độc lập 30 câu, tính kappa
- Chạy hệ thống v2 trên toàn bộ golden set; phân loại mọi câu sai vào các nhóm (truy xuất sai, đúng nguồn nhưng diễn giải sai, không từ chối khi nên từ chối…)

## Tiêu chí đạt

- [ ] có bảng nhóm lỗi xếp theo tần suất; kappa đủ cao để tin nhãn, hoặc đã sửa hướng dẫn cho đến khi đạt.

## Lý thuyết cần đọc

- [ ] Eval offline và online; vì sao cần cả hai
- [ ] Thiết kế golden set: phân bố giống câu hỏi thật, có câu khó, câu ngoài phạm vi, câu cài bẫy, câu nhiều lượt
- [ ] Viết hướng dẫn gán nhãn; đo độ đồng thuận giữa hai người gán (Cohen’s kappa)
- [ ] Phân tích lỗi: đọc từng lỗi, ghi chú tự do, rồi gom thành nhóm nguyên nhân
